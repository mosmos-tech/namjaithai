# TF-54: แหล่งข้อมูลสำหรับผู้ตรวจเนื้อหา

สถานะ: **ร่างเพื่อให้ผู้เชี่ยวชาญตรวจ ยังไม่ผ่านการรับรอง** ผู้ใช้แจ้งว่ามีผู้ตรวจแล้วและจะแจ้งผลภายหลัง เอกสารนี้ไม่ใช่หลักฐานว่ามีการตรวจหรืออนุมัติเนื้อหาแล้ว

ตารางนี้รวบรวมแหล่งทางการที่ค้นพบเพื่อช่วยผู้ตรวจ ไม่ได้ยืนยันว่าแต่ละแหล่งรองรับคำถาม ตัวเลือก หรือคำแนะนำทุกข้อของระบบ การอ้างอิงในโค้ดต้องชี้ไปยังแหล่งที่รองรับข้อความแต่ละข้อโดยตรง และต้องตรวจต้นฉบับก่อนใช้

## ประเด็นสำหรับผู้ตรวจ

- ตรวจคำถาม ตัวเลือก คำถามย่อย สัญญาณอันตราย และคำแนะนำรายข้อเทียบกับต้นฉบับ ไม่ใช้แหล่งอ้างอิงทั่วไปแทนหลักฐานเฉพาะข้อ
- ตรวจว่าเงื่อนไขคำถามย่อยและการส่งสัญญาณไปคำนวณความเร่งด่วนไม่ทำให้พลาดเหตุรุนแรงหรือขอความช่วยเหลือล่าช้า
- ตรวจข้อความแสดงต่อผู้ใช้และข้อจำกัดตามบริบท โดยเฉพาะคำแนะนำที่เกี่ยวกับการช่วยเหลือหรือเคลื่อนย้ายผู้บาดเจ็บ
- บันทึกชื่อหรือบทบาทผู้ตรวจ วันที่ ผลตรวจ ข้อแก้ไข และเวอร์ชันเนื้อหาที่ตรวจ **หลังจากได้รับผลจริงเท่านั้น**
- คงสถานะประเภทเหตุที่ยังไม่ผ่านการตรวจไว้ตามเดิม ไม่ถือว่าเอกสารนี้เป็นการอนุมัติเปิดใช้งาน
