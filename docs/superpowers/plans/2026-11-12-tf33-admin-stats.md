# TF-33 Admin Statistics Implementation Plan

**Goal:** แสดงตัวเลขปัจจุบันและสถิติห้องสั่งการที่กรองจังหวัดและวันได้ตรงกับฐานข้อมูล

**Architecture:** RPC เฉพาะแอดมินสรุปผลในฐานข้อมูลโดยไม่รวมเคสตัวอย่าง; หน้า server component อ่านผลและรายชื่อจังหวัด แสดงสรุป 4 ช่องและตารางแยกสี จังหวัด และประเภทเหตุ

**Tech Stack:** Next.js App Router, Supabase PostgreSQL, Vitest, Playwright, pgTAP

**Spec:** TF-33 ใน docs/backlog.md

## Global Constraints

- สรุปปัจจุบันกรองจังหวัด ส่วนสถิติกรองจังหวัดและวันสร้างเคสตามเวลาไทย; ปิดวันนี้ใช้เวลาปิดตามเวลาไทย
- ห้ามให้ผู้ที่ไม่ใช่แอดมินเข้าถึง RPC; ไม่รวมเคสตัวอย่าง; วันที่เริ่มต้องไม่หลังวันสิ้นสุด
- แสดงข้อมูลที่จอ 375px ได้โดยไม่ตัดเนื้อหา และไม่แสดงเวลารับเคสเฉลี่ย

## Tasks

- [ ] ทดสอบการแปลงและตรวจสอบช่วงวันที่ด้วย Vitest ก่อนพัฒนา
- [ ] เขียน RPC และ pgTAP ตรวจสถานะ วันที่ จังหวัด ประเภทเหตุ เคสตัวอย่าง และสิทธิ์
- [ ] แสดงแบบฟอร์มตัวกรอง ตัวเลขสี่ช่อง และตารางสถิติ พร้อม E2E ตรวจฐานข้อมูลและจอมือถือ
- [ ] รัน unit, typecheck, lint, pgTAP และ Playwright ตามกฎโครงการ
